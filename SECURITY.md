# Security Policy

## Supported versions

No stable release has been published yet. Security fixes are applied to the default development branch until a release support policy is established.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available. Include the affected commit or version, impact, and a minimal reproduction. If private reporting is unavailable, contact the repository maintainer through the contact route on their GitHub profile.

Do not include customer data, credentials, proprietary datasets, or model access tokens in a report.
